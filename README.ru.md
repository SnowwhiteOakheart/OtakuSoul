## 🌸 Что такое OtakuSoul?

OtakuSoul – это приложение, в котором **ИИ-персонажи** разговаривают с тобой, играют вместе с тобой в истории и **помнят**, что вы пережили вместе. Выбери персонажа – или создай своего – и просто пиши. ИИ отвечает от лица персонажа: с изображением, настроением, а при желании и с голосом и 3D-аватаром.

<p align="center">
  <img src="docs/assets/screenshots/ru/home.png" alt="Главная страница OtakuSoul: продолжить разговор, продолжить историю, найти новых персонажей" width="95%" />
</p>

* 💬 **Общение** с персонажами, у которых есть характер, чувства и память.
* 📖 **Истории:** выбери готовое приключение – ИИ рассказывает, а ты решаешь, что говорит и делает твой персонаж.
* 🎲 **Броски кубиков как за игровым столом:** по желанию правила 5e с игровым полем – движок правил решает, ИИ рассказывает.
* 🔒 **Приватно:** с локальной моделью ничего не покидает твой ПК. Без аккаунта, без телеметрии.
* 🧩 **Без возни:** мастер настройки скачивает всё нужное одним щелчком – без Python и командной строки.

## 🚀 Первые десять минут

1. **Запусти приложение.** Откроется мастер настройки и спросит язык и цветовую тему.
2. **Выбери ИИ.**
   * **Локально** – приватно и бесплатно. Карточка *«Рекомендуется для твоего ПК»* проверит видеокарту, оперативную память и свободное место на диске и подберёт подходящий набор из **модели чата, изображений и голоса** (с VoiceDesign каждый персонаж сразу говорит своим голосом из описания в карточке). Любую часть можно изменить или пропустить; кнопка *«Да, загрузить всё сейчас»* установит всё в фоне, пока ты идёшь дальше. В разделе *Выбрать самому* светофор показывает, подходят ли отдельные модели к твоему ПК.
   * **Облако** – мощная видеокарта не нужна. Выбери провайдера (OpenRouter, OpenAI, Anthropic, DeepSeek, Gemini, Mistral или свой сервер) и вставь ключ API; ссылка на страницу ключей провайдера – прямо рядом. Проще всего: **«Войти через OpenRouter»** – откроется браузер, войди, готово; без баланса приложение выберет бесплатную модель.
3. **Выбери персонажа** и при желании голос и изображения – и вперёд, в чат или сразу в историю.

Что-то не получается? **Знак вопроса** справа вверху открывает *Первые шаги* и **глоссарий**, который объясняет каждый термин одним предложением. У частых ошибок есть кнопка решения («Проверить ключ API», «Выбрать модель поменьше», «Запустить локальный ИИ»). Подробное руководство: **[Первые шаги с OtakuSoul](docs/guide-getting-started.ru.md)**.

### 📖 Истории – выбрать, сыграть, продолжить позже

Галерея историй показывает готовые приключения с жанром, длительностью и сложностью; *Для новичков* отмечает простые. У каждой истории есть превью с завязкой, спутниками и идеями для первого хода.

* **Пять стартовых историй** в комплекте – уютная, весёлая, детектив, страшилка и научная фантастика – плюс приключение 5e *«Склеп забытых теней»* в трёх актах. Связанные истории и серии отображаются как **коллекции** с обложками, а недостающие части можно сразу догрузить из хаба.
* **Как играть:** напиши, что твой персонаж *говорит*, *делает* или *думает*, шепни что-то одному спутнику или дай ведущему *режиссёрское* указание. Спутники сами берут слово и реагируют от своего лица, а не пересказываются ведущим. Нет идей? Нажми на вариант. *Дальше* продолжает историю на раунд без тебя, *Отменить* возвращает последний раунд.
* **Своя история:** мастер историй спросит жанр, твоего персонажа, спутников и завязку – с готовыми идеями для каждого жанра.
* **Спутники с памятью:** персонажи, знакомые тебе по чатам, приносят свои воспоминания в историю и в начале новой сессии рассказывают, что пережили за это время.

### 💬 Чат – персонажи с характером

<p align="center">
  <img src="docs/assets/screenshots/ru/chat.png" alt="Чат с Сиори: портрет с эмоцией, настроение и ответ" width="95%" />
</p>

* **Изображение меняется вместе с эмоцией** ответа – до **15 эмоций** на персонажа: шесть настроений, а также смущение, поддразнивание, страх, отвращение, слёзы и четыре романтических изображения (у большинства персонажей из хаба есть полный набор). Выражение ИИ выбирает сам; портрет слегка дышит и двигается во время речи – а в режиме **говорящего портрета** (Talking Head Anime 3 на процессоре, без нагрузки на видеокарту) даже один статичный рисунок двигает губами в такт речи, моргает и передаёт настроение. Вместо него можно включить **3D-аватар** (VRM, MMD, glTF из игр с загружаемыми наборами движений), **Live2D** или свободную куклу **Inochi2D** (.inp/.inx) с синхронизацией губ и собственными анимациями. Примеры всех типов уже в комплекте, ещё больше – в хабе во вкладке **Аватары**. Все модели собраны в **Библиотека → Аватары**: просмотр, настройка параметров и кадрирования, переименование и назначение персонажам одной галочкой.
* **Привязанность, энергия, настроение:** полоса сверху показывает, как чувствует себя персонаж – ИИ ведёт её сам.
* **Ответ не понравился?** Сгенерируй новый (свайп), отредактируй или продолжи с любого сообщения как новый чат.
* **Групповые чаты:** пригласи в чат ещё персонажей – у каждого своя память и свой голос. Выбирай, кто ответит следующим, или пусть говорят по кругу.
* **Пишет сам:** По желанию персонаж пишет тебе после паузы или спрашивает, когда подходит срок задуманного («Как прошло собеседование?»), а утром рассказывает сон из ваших воспоминаний – а в групповом чате вместо этого, что он тем временем делал с гостем – с временем тишины, дневным лимитом и уведомлением; отдельных персонажей можно отключить.
* **Помощь с текстом:** *Что можно ответить?* предлагает ответы, *Напиши за меня* формулирует твоё следующее сообщение, указания в ((двойных скобках)) направляют ИИ, длину ответа можно задать для каждого чата, а нежелательные слова и обороты – отфильтровать.
* **Длинные чаты** остаются быстрыми: локальная модель хранит память разговора компактно (KV-кэш q8_0, примерно вдвое больше контекста в той же видеопамяти), старые части убираются крупными шагами, чтобы уже обработанный промпт использовался повторно, и автоматически пересказываются, чтобы персонаж не терял нить.

### 🧠 Память, голос и не только

* **Персонажи помнят тебя:** после разговора память обновляется – убеждения, настроение, ваши отношения, темы и дневник от первого лица. К каждому ответу персонаж подбирает воспоминания, подходящие к разговору; устаревшие заменяются, а не дублируются (и их можно восстановить). **Планы и обещания** («Позвоню тебе завтра») запоминаются со сроком и всплывают, когда приходит время. *Навести порядок в памяти* объединяет пересекающиеся записи после твоего подтверждения. Каждое воспоминание показывает свой источник; его можно исправить, закрепить или забыть.
* **Голоса и голосовой звонок:** синтез и распознавание речи работают локально (Qwen3-TTS, Chatterbox, Kokoro, TADA) или через Edge-TTS/ElevenLabs. Во время **голосового звонка** персонажа можно в любой момент **перебить** – озвучка и генерация сразу остановятся, твоя реплика бесшовно станет следующим ходом, а ответ сохранится ровно до того места, которое ты успел услышать. Кнопка *«Сказать фразу»* за один проход проверяет уровень микрофона, распознавание и голос персонажа. **Клонирование голоса** по короткой записи – диалог сам предложит лучший фрагмент; только с согласия говорящего. По желанию **голос рассказчика** читает *действия*, а персонаж произносит свои реплики – как в аудиоспектакле.
* **Голоса с характером:** Qwen3-TTS 1.7B говорит в выбранном стиле и с чувством – шёпотом, грустно, взволнованно – под стать ответу. Карточка может описать свой голос (тембр, возраст, темп), а VoiceDesign создаёт по таким описаниям несколько голосов.
* **Изображения:** сцены можно рисовать локально через stable-diffusion.cpp (от SD 1.5 до FLUX.2). Персонаж выглядит как на своём портрете и по желанию присылает тебе **селфи** в чат.
* **Модели, адаптеры и замер скорости:** загрузки идут сразу в 8 соединений и продолжаются после обрыва, даже после перезапуска; разделённые GGUF-файлы и подходящий файл зрения загружаются вместе. Каждая модель хранит свои настройки, поддерживает **адаптеры (LoRA)** для литературного стиля или ролевой игры без цензуры, а кнопка *«Проверить скорость»* измеряет и сравнивает быстродействие прямо на твоём ПК.
* **Питомец на рабочем столе и компаньон:** персонаж свободно живёт на рабочем столе как **3D-аватар, модель Live2D, кукла Inochi2D или говорящий портрет** (клики мимо фигуры проходят насквозь, плавный масштаб по `Ctrl + колесо мыши`, мягкая тень под ногами). Он ходит с гравитацией между несколькими мониторами, его можно перетаскивать и бросать, а в Windows он стоит, сидит, запрыгивает на грани окон и ездит вместе с ними. Гормоны и время суток влияют на поведение (ночью говорит тише, от аккумулятора экономит заряд, в полноэкранном режиме ставится на паузу, кивает в такт музыке). Он реагирует на поглаживание по голове, «дай пять» и держание за руку, прибегает к курсору по команде *«Иди сюда»*, показывает ответы фраза за фразой синхронно с голосом и позволяет быстро написать прямо рядом с ним (*«Сказать что-нибудь …»*). Переключается из трея или настраиваемым сочетанием клавиш (`Ctrl+Alt+Shift+P`); как компаньон умеет искать в интернете, читать буфер обмена или управлять музыкой – любое чувствительное действие требует твоего подтверждения.
* **Твой язык:** немецкий, английский, русский и японский уже есть. Другие языки интерфейса приходят из хаба или как JSON-файл, который ты импортируешь в настройках, – без новой версии приложения.
* **С телефона:** в той же Wi-Fi-сети можно общаться со смартфона или планшета через QR-код.

## 💻 Подойдёт ли мой ПК?

| Твой ПК | Рекомендация |
|---|---|
| Без отдельной видеокарты / ноутбук | **Облачный ИИ** – работает на любом компьютере, нужен только ключ API. |
| Видеокарта с 6–8 ГБ памяти | **Локально** с компактной моделью (Gemma 4 E4B, Qwen3.5 9B); мастер подберёт подходящую. |
| 10–16 ГБ | **Локально** с Gemma 4 12B – быстрая, видит изображения, остаётся место для озвучки и локальных изображений одновременно. |

## 🛠️ Для опытных пользователей и разработчиков

### 🧭 Переход с SillyTavern, Backyard AI или Character.ai?

* **Единое настольное приложение:** Не нужно настраивать Node.js, окружение Python или вручную подключать внешние серверы. Всё работает нативно в одном приложении (Tauri 2 и Rust) со встроенными движками для локальных LLM, генерации картинок, клонирования голоса, говорящих 2D-портретов и аватаров 3D, Live2D и Inochi2D.
* **Совместимость с карточками и лорбуками:** Ваши карточки SillyTavern (PNG/JSON), персонажи Chub и лорбуки импортируются и экспортируются без проблем. Вся текущая коллекция работает сразу.
* **Что можно перенести:** кроме персонажей, миров и лорбуков также **regex-скрипты** SillyTavern, **наборы быстрых ответов**, пресеты сэмплеров и системные промпты. Regex-скрипты действуют на твои сообщения, ответы, только на отображение или только на промпт.
* **Честно о расширениях:** системы плагинов для стороннего кода (пока) нет – расширения из других фронтендов и команды STscript (slash-команды в быстрых ответах) не работают; импорт их пропускает и сообщает, сколько их было. Instruct- и контекстные шаблоны не нужны, потому что OtakuSoul использует шаблон чата самой модели.
* **Больше, чем чат:** Помимо свободного ролевого чата, OtakuSoul предлагает сюжетные истории, тактические приключения по правилам 5e на клеточном поле и автоматическую четырёхслойную когнитивную долговременную память в SQLite.

### Данные и приватность

* Данные профиля хранятся в папке пользовательских данных (`~/.local/share/otakusoul` в Linux, `%APPDATA%\snowwhite\otakusoul\data` в Windows, `~/Library/Application Support/com.snowwhite.otakusoul` в macOS); `OTAKUSOUL_HOME` перенаправляет всё, включая хранилище webview.
* Ключи API хранятся в системной связке ключей, никогда открытым текстом. Журнал промптов ключей не содержит.
* *Интеграции → Бэкап* сохраняет персонажей, персоны, лорбуки, истории, чаты и воспоминания, настройки и клонированные голоса в один файл – ты выбираешь, что туда войдёт.

### Другие способы установки

* **Скрипты для Linux:** `install.sh` устанавливает в `~/.local/bin` с пунктом меню; Arch: `cd packaging/aur && makepkg -si`.
* **Скрипт для Windows:** `powershell -ExecutionPolicy Bypass -File .\install.ps1` устанавливает для текущего пользователя с ярлыками.
* **Скрипт для macOS:** `install-macos.sh` копирует приложение в *Программы* и снимает карантинную метку.
* **Mac на Intel:** готового пакета нет – собрать из исходников (см. ниже).

```bash
npm run tauri build        # устанавливаемый пакет для твоей системы
```

Проверки качества (CI для проверок нет – всё запускается локально; GitHub Actions только собирает релизные пакеты):

```bash
npm run check      # oxlint, tsc, vitest, cargo fmt, clippy, cargo test
npm run types:gen  # типы TypeScript из структур Rust (ts-rs)
npm run e2e        # сквозные тесты против мок-LLM (tauri-driver)
npm run e2e:perf   # замер длинного чата (1000 сообщений)
```

Скриншоты для README создаются командой `xvfb-run -a node e2e/readme-screenshots.mjs ru` (или `de`, `en`). Заметки для участников и ИИ-ассистентов: [AI.md](AI.md).
