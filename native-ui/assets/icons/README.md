# Lucide-Symbole

Diese SVGs stammen aus dem bereits im Repository installierten `lucide-react` **1.70.0** und entsprechen
den Symbolen des Tauri-Frontends. Sie wurden einmalig mit `react-dom/server` als statische SVGs exportiert.
In der nativen App werden ausschließlich die eingebetteten SVG-Dateien durch Iced gerendert;
React und JavaScript sind dafür nicht zur Laufzeit erforderlich.

Die vollständigen ISC-/Feather-Lizenzhinweise stehen in [`LICENSE`](LICENSE). Die Grundkontur ist
24 × 24 mit einer Strichstärke von 2. Die native Oberfläche kann die Farbe für den aktiven Zustand ändern.
