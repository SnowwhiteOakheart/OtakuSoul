# Avatar-Prompts für das No-Game-No-Life-Preset

Für jede der 8 Karten liegt aktuell nur ein einfacher Platzhalter (farbige Fläche mit Anfangsbuchstabe) unter
dem unten genannten Dateinamen. Bitte generiere zu jedem Prompt ein Bild und speichere es **exakt unter dem
angegebenen Pfad**, überschreibe damit den Platzhalter. Format: PNG, quadratisch, empfohlen 512x512 oder
768x768 (die App skaliert automatisch).

Stil-Vorgabe für alle Bilder, damit das Set einheitlich wirkt: **moderner Anime-/Key-Visual-Stil, sauberes
Cel-Shading, kräftige Farben, Brustporträt (Kopf bis Brust), neutraler oder leicht atmosphärischer
Hintergrund, Blick zur Kamera oder leicht seitlich.** Es handelt sich um Charaktere aus *No Game No Life* -
bitte am jeweiligen kanonischen Aussehen orientieren, keine 1:1-Kopie eines bestehenden Screenshots, sondern
ein eigenständiges, im Stil passendes Porträt.
